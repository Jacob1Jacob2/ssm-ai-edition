CLASSIC SSM SOUND AND PARTICLE AUDIT — 2026-11-09

Target: original Java Mineplex SSM before the May 2023 shutdown.
The 2026 Remastered/Revamped overhaul is explicitly excluded.

Evidence and limits
I inspected the active local kit loadouts and audiovisual calls, 65 effect-related classes in a 2015 source snapshot, and 69 classes in a later legacy 1.8 source-recovery fork. The 2015 snapshot was committed in June 2016. The later fork is pinned to its May 24, 2024 commit, but contains the old 1.8 game implementation, not the 2026 overhaul. It is a third-party recovery fork, not an official final-May-2023 release. Agreement between the two artifacts is stronger evidence than either alone.

Only functional facts (sound identifiers, volume/pitch, particle families and event placement) were used. No third-party gameplay source was imported. These changes are evidence-backed corrections, not a claim of exact final-2023 parity. Historical code does not establish every sound as it was heard by every client/version/resource pack; no recorded-video listening comparison was performed in this pass.

Important mapping corrections
- The project's Player.playSound helper reversed volume and pitch when calling Bukkit. Fixed the argument order.
- Old random.click maps to block.dispenser.dispense, not block.dispenser.fail.
- Old random.splash maps to entity.fishing_bobber.splash. The neutral/player swimming splash event is different.
- Old EXPLODE particle means the small gray puff (modern POOF); LARGE_EXPLODE means EXPLOSION; HUGE_EXPLOSION means EXPLOSION_EMITTER.
- Cosmetic fireworks must not call modern Firework.detonate(), which can introduce extra damage. The new burst helper sends the visual entity status and removes the temporary rocket.

Unfinished work revealed by the audit
- Base Blizzard and Fish Flurry still contain placeholder implementations. These need gameplay implementation, not just a sound substitution.
- Several reconstructed abilities retain different projectile shapes, timing, or animations: notably Inferno, Daze, Villager professions/scatter, Needler burst timing, clone death debris and some Horse smoke geometry.
- Modern client sound samples, texture packs and audio settings can differ from old Minecraft. Exact perceived loudness/visual parity still needs side-by-side footage or in-game comparison.
- Modern-only classes for future kits are still in the source tree but are not used as classic reference material.
- User-custom tiered Smash powers intentionally remain custom and were not reset to old Mineplex ultimates.

Preserved
All kit YAML/stat tables, resource-pack sprites, menus, scoreboard, lobby/map code, bots, and custom Smash code are byte-for-byte unchanged from the backup. The user's quieter recharge pling remains volume 0.3. Only audiovisual Kotlin code and the sound helper changed.
